# Contributor/agent contract

Preserve the goal: natural language in, useful app out, no developer setup for end users. The runtime is shared conventional software; generated apps are executable structures. Do not equate machine-oriented representation with raw binary, or claim that no source code exists anywhere.

Keep starter/demo mode explicit. Never relabel a rule-based template as a live AI response. Never report native delivery, cloud persistence, secure accounts, or speed/cost wins without implementation and evidence.

Do not put provider keys in client assets or ask ordinary users to paste API credentials. Public inference must be operator-funded/configured and abuse-protected. Do not relax fail-closed controls to make a demo look complete.

Validate untrusted models and references. Render text as text. Reject incompatible changes before changing records. Never add eval, Function constructors, arbitrary model script injection, or unbounded external operations to the runtime.

Run `node --test tests/*.test.mjs`. Keep optional browser/deployment requirements separate from end-user requirements. Update VERIFICATION.md honestly when testing is simulated, blocked, mocked, or incomplete. Do not change any unrelated repository, including LOOP.
