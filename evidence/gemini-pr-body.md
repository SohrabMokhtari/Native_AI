The v3 builder embeds Groq transport and requires a separate completion turn after validating an app. This adds an opt-in native Gemini adapter behind a provider-independent loop, bounded dependency inspection, compact repair feedback and combined submission/finalization. Groq remains the production configuration default; legacy routing, interpreter operations, exports and acceptance constraints are preserved.

Independent V3_AI_PROVIDER / V3_AI_MODEL overrides isolate v3 experiments. Gemini uses native function declarations/results and private bounded opaque continuation. Both transports use manual redirects, enforced fetch/body cancellation, bounded responses and deadlines, without automatic retry or fallback. The studio identifies its provider and Gemini privacy terms. Repair feedback identifies schema paths and draft state, usage accounting preserves unknown thinking counts, and failed traces retain bounded checks across repair transport failures. The live evaluation CLI prints progress/heartbeats on stderr and JSON on stdout.

A separate wrangler.gemini-test.jsonc targets native-ai-gemini-test with distinct rate-limit counters and preserved dashboard variables. Fresh deployment fails closed until the owner adds encrypted credentials, test-host Turnstile and runtime enablement. Build settings, rollback and current official sources are documented in GEMINI_BUILDER.md.
